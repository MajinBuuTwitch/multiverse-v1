CROSS-CUTTING LESSONS (for the section's conclusion)
------------------------------------------------------------------------------------------
1. Agents' chat summaries are not results; only files are (paper Limitation 6).
2. A claim of verification is not verification: require the tool output, not the statement.
3. Give reviewers one document; agents blend similar documents in a shared workspace.
4. Use each model where it was verified reliable: file and hash checks vs prose review.
5. Every family, including the planner's, made errors that another family or the files caught.
